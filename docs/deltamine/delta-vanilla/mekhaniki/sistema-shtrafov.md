# Штрафы

***

На нашем сервере работает официальная система штрафов. Она используется полицией и судом сервера для наказания правонарушителей и автоматической выплаты материальных компенсаций пострадавшим игрокам.

Все средства, выплаченные по штрафу, поступают **напрямую на банковский счёт пострадавшего**.

<figure><img src="../../../.gitbook/assets/fines_list.png" alt=""><figcaption><p>Список активных штрафов в банковском терминале</p></figcaption></figure>

## Как устроен штраф:

Когда сотрудник полиции выписывает штраф, нарушитель получает звуковое уведомление и кликабельное сообщение в чате. Каждому штрафу присваивается уникальный номер **#ID** и карточка со следующей информацией:

* **Крайний срок выплаты:** точная дата и время, до которого необходимо закрыть задолженность.
* **Сумма штрафа:** размер компенсации в АР.
* **Причина:** основание вынесения штрафа (пункт правил или описание инцидента).
* **Пострадавший:** игрок, которому будут переведены средства.
* **Выписал:** сотрудник полиции или судья, оформивший штраф.

{% hint style="info" %}
Посмотреть список своих штрафов можно через терминал <mark style="color:$primary;">`/bank`</mark>, нажав на иконку **«Ваши штрафы»**, либо кликнув по системному уведомлению в чате при входе на сервер.
{% endhint %}

***

## Оплата штрафа:

1. Откройте меню штрафов через <mark style="color:$primary;">`/bank`</mark> ➔ **«Ваши штрафы»**.
2. Нажмите на карточку штрафа, который хотите погасить.
3. Выберите свой банковский счёт, с которого необходимо списать АР.
4. После списания штраф считается закрытым, а пострадавшему мгновенно начисляется компенсация на его основной банковский счёт.

***

## Прощение штрафа пострадавшим:

Если конфликт между игроками был урегулирован мирным путём, **пострадавший игрок** имеет право добровольно простить штраф без выплаты компенсации.

{% hint style="info" icon="terminal" %}
<mark style="color:$primary;">`/forgive <Игрок> <ID_Штрафа>`</mark> — Простить выписанный в вашу пользу штраф
{% endhint %}

{% hint style="warning" %}
Простить штраф может **только пострадавший**, указанный в карточке этого штрафа.
{% endhint %}

***

## Сроки и последствия неуплаты:

Относитесь к оплате штрафов ответственно. Затягивание срока влечёт за собой автоматические санкции:

{% hint style="danger" %}
* **1-я просрочка:** если штраф не оплачен до дедлайна, его сумма **автоматически удваивается (x2)**, а срок продлевается ещё на **14 дней**. Штраф получает статус «Просроченный».
* **2-я просрочка:** если удвоенный штраф не оплачен в течение повторных 14 дней, нарушитель получает **автоматический перманентный бан** на сервере по причине: `Вы просрочили штраф #ID 2 раза`.
{% endhint %}

***

## Команды для полиции:

Выписка и досрочное аннулирование штрафов доступны сотрудникам правоохранительных органов:

{% hint style="info" icon="terminal" %}
<mark style="color:$primary;">`/fine add <Нарушитель> <Пострадавший> <Сумма> <Срок> [Причина]`</mark> — Выписать штраф нарушителю

<mark style="color:$primary;">`/fine remove <Нарушитель> <ID_Штрафа>`</mark> — Снять ошибочный или отменённый штраф
{% endhint %}

<details>

<summary>Доступные сроки при выписке штрафа</summary>

В качестве аргумента `<Срок>` полиция может указать:
* <mark style="color:$primary;">`1-Неделя`</mark> (7 дней)
* <mark style="color:$primary;">`2-Недели`</mark> (14 дней)
* <mark style="color:$primary;">`3-Недели`</mark> (21 день)
* <mark style="color:$primary;">`4-Недели`</mark> (28 дней)

</details>
