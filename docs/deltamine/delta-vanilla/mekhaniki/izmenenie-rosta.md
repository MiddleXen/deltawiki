# Изменение роста

***

Изменения роста доступно только игрокам с подпиской <mark style="color:$primary;">**PLUS**</mark>

Вы можете изменить рост **от 0.7 до 1.5**. Изменения роста можно использовать как для красоты, так и для прохождения разных пространств.

<figure><img src="../../../.gitbook/assets/0626 (3)(1).gif" alt=""><figcaption></figcaption></figure>

## Использования:

{% hint style="info" icon="terminal" %}
* <mark style="color:$primary;">`/resize [Размер]`</mark>  — Что бы поменять рост
{% endhint %}
