# Подпись предметов

***

Подпись предметов позволяет оставить ваш несмываемый никнейм, дату создания и уникальное описание прямо в свойствах предмета. Эту механику активно используют для заверения юридических договоров, маркировки личного снаряжения и памятных сувениров.

{% hint style="info" %}
Возможность подписывать предметы доступна игрокам с активной подпиской <mark style="color:$primary;">**PLUS**</mark>.
{% endhint %}

### Как работает подпись:

<div><figure><img src="../../../.gitbook/assets/ima2ge.png" alt=""><figcaption><p>Подпись с описанием</p></figcaption></figure> <figure><img src="../../../.gitbook/assets/image (2).png" alt=""><figcaption><p>Подпись без описания</p></figcaption></figure></div>

* При подписании к предмету добавляются строки: **«Подписано: Ник»** и точная **«Дата: ДД.ММ.ГГ ЧЧ:ММ»**.
* К подписи можно добавить произвольное описание длиной **до 20 символов**.
* **Защита от удаление:** удалить подпись с предмета может **только тот игрок, который её поставил**. Чужую подпись стереть невозможно!

***

### Использование:

{% hint style="info" icon="terminal" %}
* <mark style="color:$primary;">`/sign`</mark> — Подписать предмет в руках без дополнительного описания
* <mark style="color:$primary;">`/sign [Описание]`</mark> — Подписать предмет с кастомным комментарием (до 20 символов)
* <mark style="color:$primary;">`/sign Удалить`</mark> — Снять свою подпись с предмета в руке
{% endhint %}
