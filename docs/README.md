# Добро пожаловать!

{% hint style="info" %}
**Мы** **ванильный**, **приватный сервер** - **DeltaMine!** Ванильный Minecraft сервер. Мы сохраняем оригинальную атмосферу игры, добавляя интересные и прикольные улучшения, особо не влияющие на игровой процесс.
{% endhint %}

***

### Основная информация

> **Айпи:&#x20;**<mark style="color:$primary;">**delta-mine.ru**</mark>\
> **Доп.айпи:&#x20;**<mark style="color:$primary;">**delta-mine.fun**</mark>\
> **Версия:&#x20;**<mark style="color:$primary;">**26.2**</mark>

### Что бы попасть на наш сервер, вам нужно:

{% stepper %}
{% step %}
#### Ознакомится с правилами и информации

Прочитать правила, ознакомиться с информацией, также сервера с часто задаваемыми вопросами и с механиками сервера.
{% endstep %}

{% step %}
#### Подать заявку или купить проходку

Подать заявку можно на нашем [Дискорд](https://discord.gg/uasRKwrgGb) сервер в канале [подать-заявку](https://discord.com/channels/1415103671468949646/1508806233191088208). После откроется окно с таблицей, которую вы должны заполнить. После открытия заявки наши стажеры могут задать вам дополнительные вопросы. Рассмотрение заявки может занимать как несколько часов, так и несколько дней. Если вы не хотите ждать и сразу хотите перейти к 4 пункту, вы можете купить проходку в нашем [магазине](https://store.delta-mine.ru).
{% endstep %}

{% step %}
#### Одобрение или отклонение заявки

Как вашу заявку одобрят, вам выдастся роль <mark style="color:$primary;">участник проекта</mark>, и откроются приватные каналы в Дискорд и выдастся проходка на сам сервер. А если вашу заявку отклонили, не расстраивайтесь вы сможете снова подать заявку через неделю.
{% endstep %}

{% step %}
#### Зайти на сам сервер

Теперь, как у вас есть проходка, вы можете зайти на сам сервер по айпи <mark style="color:$primary;">delta-mine.ru</mark> Вы окажетесь в лобби сервера. Перед вами будет нпс, кликните по нему. Вас попросит привязать дискорд (подробнее: [Как привязать Discord?](dobro-pozhalovat/chasto-zadavaemye-voprosy.md#kak-privyazat-discord)), после этого вы сможете попасть на сам сервер и наслаждаться игрой.
{% endstep %}
{% endstepper %}
